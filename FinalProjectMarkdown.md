**Final R Project: librarymetrics**

This is the Markdown file for the librarymetrics package that I, *Arthur Christoffersen*, am creating for my R Programming Course. This package is meant to enable the quick production of graphs and data analysis from a series of CSV files, which hold the weekly data regarding a hypothetical library's usage metrics.

At the moment, there are three main functions planned for this project, though there are likely to be more added in the future as this package develops. These are:

-   *selectDate*

-   *readData*

-   *genGr*

The *selectDate* function queries the user to provide the data range for the data set by however many weeks. It consults the current date based on the system's clock and determines how many weeks back it should look for data. This provides the *readData* function the knowledge on the range it should search when reading the CSV files.

The *readData* function is meant to either read the CSV files for the past however-many weeks and create a series of tables compiled into a single dataframe. This places all the data in a single accessable location and because all the dimensions in the dataframe are uniform, as are the CSV files, this makes it easier to conduct data analysis on the data using the following function.

The *genGr* function is meant to take the dataframe created by the *readData* function and construct a series of graphs based on the data. The graphs created will showcase how the usage for certain library services fluctuated weekly over the period of time selected. This function will display bar charts to show fluctuation over time for individual library services and a pie chart to break down how popular services were compared to each other.
